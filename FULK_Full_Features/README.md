# FULK Android — Full Feature Local Prototype

Project Android native Kotlin + Jetpack Compose, application ID `id.fulk.app`.

## Build
Open this folder in Android Studio or upload it to GitHub Codespaces. Use JDK 17 and Android SDK 35. Run Gradle sync, then `./gradlew assembleDebug` (a Gradle wrapper may need to be generated by Android Studio if absent).

## Included functioning local flows
- Home with six features and Qur'anic context screen before each feature.
- Persistent theme preference (system/light/dark).
- FULK Time: save daily limit, reminder lead time and app group; shortcut to Android Usage Access settings.
- FULK Shield: local heuristic checks for simple risk indicators.
- FULK Check: save claims and source links, honestly marked unverified because no fact-check API is configured.
- Suara FULK: save local reports and status history; not a shared moderation backend.
- FULK Reflect: activity logging, local water calculation, journal entries.
- FULK Learn: lesson content and quizzes with answer feedback.

## Important honest limitations
This is a fuller functioning local prototype, not a production-ready release. Automated cross-app monitoring, Smart Pause overlay/mandatory lesson gate, website blocking, real-time fact-check API, community reports/backend, scheduled notifications, anti-repeat activity rules, backup/sync and automated device usage ingestion are not represented as active. Those need additional Android services/permissions and/or backend/API credentials. Qur'anic Arabic and translations must be reviewed against an authoritative mushaf/translation before release.

## Local data
Stored in Android SharedPreferences on the device. No report or claim is sent externally.
